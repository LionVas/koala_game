# Коала-кликер

Стартовый проект для курса **«Проектирование и разработка игровых приложений»**.

Стек: **TypeScript + Phaser + Vite + GitHub Pages**.

Небольшая браузерная игра: кликай по коале, зарабатывай очки и покупай вычислительные мощности. Первая цель — 300 очков, затем она повышается на 300: 600, 900 и дальше. Оверселлинг полностью останавливает доход до первой покупки мощности, а после неё временно снижает награду за клик. Блокировку IP можно переждать или снять покупкой смены IP.

Задание первой практики и домашней работы: [`ASSIGNMENT_01.md`](./ASSIGNMENT_01.md).

- **Node.js 22 LTS** (или Node.js >= 20.19)
- **Git**
- **VS Code** или другая IDE

## 2. Первый запуск

```bash

```

Vite напечатает адрес локального сервера. Обычно это:

```text

```

Открой его в браузере.

## 3. Как играть и где менять баланс

Нажимай на коалу мышью или пальцем. Как только накопишь достаточно очков, покупай мощность справа: каждая покупка увеличивает обычную награду за клик на 1. Покупки уменьшают баланс, но не сбрасывают общий заработок и прогресс к цели.

Во время оверселлинга без купленных мощностей клики дают 0 очков. После первой покупки награда уменьшается вдвое с округлением вниз, но остаётся не меньше 1 очка. Мощность можно купить и во время помехи, если хватает баланса.

При IP-блокировке появляется кнопка «Сменить IP»: цена — 10% текущей цели, округлённые вверх (30 очков при цели 300, 60 при цели 600). Покупка списывает очки из баланса и сразу снимает блокировку. Если денег не хватает, кнопка недоступна; блокировка пройдёт сама через 5 секунд.

После достижения цели игра продолжается с новой целью на 300 очков выше; баланс и мощности сохраняются. Кнопка «Начать заново» сверху сбрасывает сессию, включая цель, заработок и мощности.

Игровые правила и константы баланса находятся в файле:

```text
src/game/GameScene.ts
```

В начале файла можно изменить начальную цель (`INITIAL_GOAL`), шаг её роста (`GOAL_INCREMENT`), долю цены смены IP (`IP_CHANGE_COST_RATE`), стоимость улучшений, время до помех и их длительность. Изображение коалы загружается из `Koala.png` в корне проекта.

## 4. Проверка production build

Перед публикацией:

```bash
npm run build
```

Если команда завершилась без ошибок, итоговая версия находится в папке `dist/`.

Её можно проверить локально:

```bash
npm run preview
```

## 5. Публикация на GitHub Pages

В репозитории уже есть workflow:

```text
.github/workflows/deploy.yml
```

После push в ветку `main` GitHub автоматически собирает проект.

Для первого включения Pages:

1. открой репозиторий на GitHub;
2. **Settings → Pages**;
3. в **Build and deployment → Source** выбери **GitHub Actions**;
4. открой вкладку **Actions** и дождись успешного `Deploy to GitHub Pages`;
5. ссылка на игру появится в deployment и в разделе Pages.
